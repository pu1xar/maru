## 4. Codex app-server protocol types

- Source: OpenAI Codex, https://github.com/openai/codex, Copyright 2025 OpenAI, Apache License 2.0
- Used in `apps/server/src/codex/protocol/`: 785 files (784 `.ts` files and `CODEX_VERSION`), the output of `codex app-server generate-ts`. The files are generated by ts-rs from the Codex Rust sources and hold TypeScript types only

- License text: section 9.3

The comment is reproduced in full in section 9.9
- License texts: section 9.4 (`@xterm/xterm`), section 9.5 (`@xterm/addon-fit`) and section 9.9 (the `xterm.css` notice)

## 8. Terminal color schemes

- Used in `apps/web/src/lib/terminalTheme.logic.ts` (read by the Android app too): the colors of the terminal mode's color sets. Only color values (hex numbers) are taken from each scheme's public palette, mapped to maru's roles (background, text, Claude mark, ok, error, warning, accent, plan, accept). No source code of these projects is copied
  - Catppuccin Mocha and Catppuccin Latte: `https://github.com/catppuccin/palette` (`palette.json`, v1.8.0), MIT License, Copyright (c) 2021 Catppuccin (section 9.10)
  - Dracula: `https://github.com/dracula/alacritty` (`dracula.toml`), MIT License, Copyright (c) 2018 Dracula Theme (section 9.11)
  - Gruvbox Dark: `https://github.com/morhetz/gruvbox` (`colors/gruvbox.vim`), MIT License by the `package.json` of the repository (author Pavel Pertsev). The repository has no license file, so section 9.12 gives the MIT text with that author as the holder
  - Solarized Dark: `https://github.com/altercation/solarized`, MIT License, Copyright (c) 2011 Ethan Schoonover (section 9.13)
  - GitHub Dark and GitHub Light: `https://github.com/primer/github-vscode-theme` (MIT License, Copyright (c) 2020 Primer, section 9.14) with `@primer/primitives` 7.10.0 (MIT License, Copyright (c) 2018 GitHub Inc., section 9.15)
- The "iTerm" and Claude Code color sets are values read from the iTerm profile of the author and from the Claude Code CLI bundle (the `source` of each set names them). The "maru brown" set is maru's own
- The color sets are mapped, not copied: the file derives text, rule, diff and chip colors from these palettes by contrast rules, so the shipped values differ from the schemes' own
